Task Specification: Develop ZotPrep v5 – An Intelligent Biomedical Reference Resolution & Zotero Automation Platform
Objective

Redesign the existing monolithic zotprep.py into a modular, production-quality application that automatically resolves manuscript references with >99% accuracy, creates Zotero items, and produces a Word document ready for Zotero ODF Scan. The system is optimized specifically for biomedical literature (systematic reviews, meta-analyses, clinical manuscripts).

The guiding philosophy is:

Find the correct paper first, then retrieve metadata.

Do not rely on CrossRef bibliographic search as the primary search mechanism.

Current Problems

The current implementation suffers from several architectural limitations:

Relies primarily on CrossRef bibliographic search.
Searches using the entire reference instead of the extracted title.
Performs poorly on:
GBD Collaborator papers
consortium publications
WHO reports
books
editorials
review articles
Limited candidate scoring.
No persistent cache.
Monolithic codebase.
Manual intervention is still required for many references.

The redesign should eliminate these weaknesses.

Search Strategy

The search pipeline should prioritize deterministic identifiers before free-text searching.

Priority 1

If reference contains:

DOI
PMID
PMCID

Resolve immediately.

No search should occur.

Priority 2

If no identifier exists:

Extract the paper title.

Search only using the title.

Do not search the entire reference string.

Hybrid Search Layer

Run multiple search providers in parallel.

Supported providers:

Google Search (primary discovery engine)
PubMed
CrossRef
OpenAlex
Semantic Scholar

Each provider independently returns candidate papers.

Candidate Aggregation

Merge all candidates into one pool.

Deduplicate identical papers.

Normalize metadata.

Confidence Engine

Every candidate receives a weighted confidence score.

Scoring signals include:

Exact DOI
PMID
PMCID
Exact title match
Fuzzy title similarity
First author
Collaborator name (e.g. GBD)
Publication year
Journal
Volume
Issue
Pages
Publisher
